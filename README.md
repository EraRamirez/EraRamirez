### 🔍 Engineering Focus & Technical Approach

*   🎨 **Design-to-shipped, closed by one person:** I design flows in Figma and implement them myself — no separation between the design file and the production screen. That loop includes iterating against live user feedback, not just static specs.
*   🔧 **Production Troubleshooting & Data Integrity:** I focus on building resilient user interfaces. Experienced in identifying API contract gaps, handling out-of-sync backend endpoints, and implementing frontend data-guards (optional chaining, strict error handling) to keep mission-critical workflows reliable.
*   🤝 **Stakeholder Alignment & Delivery:** Comfortable stepping out of the codebase to partner with product and operations stakeholders. I participate in technical discovery, requirements gathering, and milestone demos to ensure software deliverables drive high operational adoption.
*   💻 **Defensive Programming:** I design reusable UI components optimized for complex business logic, such as role-based user flows and hardware API integrations (POS peripherals), ensuring secure and error-free execution in production environments.
